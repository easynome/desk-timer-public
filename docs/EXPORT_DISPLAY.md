# 导出展示与运行诊断

2026-10-16，Codex；v1.2.1。

机器消费优先使用 JSONL。`time-entries.csv` 保留原始文本，字段中的 CR、LF、引号与逗号按 CSV 转义；它不适合直接作为不可信数据的 Excel 展示文件。

`time-entries.excel.csv` 为面向人的展示变体：保留 UTF-8 BOM，对开头或前导空白之后出现 `= + - @` 及全角变体的文本、以 Tab/CR/LF 开头的文本，在引号内添加 Tab 前缀。原字段中的引号仍成对转义。普通文本与数值字段保持原状。原始 CSV/JSONL 不添加此标记，内部数据库和导出 schema_version 不改变。

处理依据：[OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)。OWASP 明确说明表格软件行为有差异，没有适用于所有软件与下游处理的统一 CSV 清洗方式。此处验证了导出字节与字段边界，未实测当前电脑 Excel 的打开、另存、再打开流程；不宣称跨软件或再次加工后都安全。Tab 是展示标记，也是实际数据的一部分，因此该文件不能替代机器原始导出。

时间线增加“补录/实测”来源提示，来源来自库中的 origin，而不是从时长猜测。待确认标记继续独立显示。

运行诊断位于 TIMER_HOME 的 `logs/runtime-0.log` 至 `runtime-2.log`，约 512 KB/份轮转；最多超出一条有界日志记录，不增加常驻线程。只保存时间、操作类别、成功/恢复、异常类，不保存任务正文、笔记、窗口标题、原始异常消息或完整堆栈。正常心跳不落盘。覆盖启动、导出、心跳、inbox 批次异常、备份、内置音频、工作台操作和未捕获异常；其他界面的已捕获失败与 inbox 逐行拒绝仍沿用界面提示/拒绝文件，不能说所有故障均已覆盖。工作台→偏好提供诊断状态刷新与日志目录入口。状态仅表示本进程记录到的故障，不是全面健康探针。
