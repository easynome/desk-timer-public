# v1.2 实施与验收

2026-10-16，Codex；依据用户当前明确要求。

按依赖串行推进：

1. P1：inbox 同库幂等回执与事务、待办完成补录事务；迁移仅增加内部表，导出 schema 保持 1.2.0。注入标签/关联/文件台账失败，重试不能多记时间。
2. 小面板与工作台：紧凑模式、可关闭的进度平滑动画、任务列表（开始番茄/完成/补录）、按归属日的只读时间线、常用设置入口。时间线有数量上限，不对并行时间简单相加。
3. 休息：全屏覆盖各显示器；普通休息允许延后 5 分钟或跳过进入下一番茄。延后期间不虚记休息；跳过保留实际已休息长度。
4. 连续使用保护：Windows 会话末次输入时间，每 5 秒采样。默认累计到 90 分钟进入 10 分钟强制休息；连续离席或实际休息满 5 分钟才重置。短暂停表、切任务和重启不清零；休眠/长采样间隙不直接计入使用。只记录使用累计，不捕获按键内容。
5. 音效：系统新短信、CC0 风铃/滴答、静音；可试听。普通提醒尊重勿扰和全屏声音设置；强制休息的覆盖按用户本次授权执行。
6. 回归、便携打包、内存与视觉验收、GitHub 提交。日常升级使用 tools/install-update.ps1：用户已于 2026-10-16 明确授权直接关闭安装路径对应的进程后替换；先验证 staging、保留旧镜像及停写数据快照，不半覆盖活动程序。

强制模式不提供普通“延后/跳过”。保留明确的紧急结束入口，不锁操作系统或拦截系统快捷键；紧急结束不认作完成休息，不清零累计。被休息自动暂停的工作段保留暂停状态，用户主动继续后才再次计时。重启恢复沿用对账，不自动恢复历史工作。

设置默认：连续使用保护开启，阈值 90 分钟，强制休息 10 分钟；普通休息全屏可选；动画默认关闭。达到阈值优先处理休息，即使计时器界面隐藏或未开始任务。休息阈值为产品约束，不是医学建议。

持续使用判据补充：运行中的工作计时或前台全屏优先于“无输入”；长时间阅读/视频不因没有键鼠事件清零。其余场景的离席按当前会话无输入5分钟推断，不能证明实际在场。真实计时事实独立于此启发式判据。

已取消：托盘闪烁，保留状态换色。暂缓 CLI 四条（export/entries/note/start），先保留稳定的导出与 inbox 通道。旧设计中的 `timer start` 不是当前 inbox 补录，不能混称已经实现。

其他旧需求处理：失焦隐藏、全屏声音、重置位置纳入常用设置；“加 5 分钟”只调整提醒目标，不改累计时长。只读 DB 副本、localhost API、历史修改和标签管理继续后置。

实施结果：上述功能与P1修复已完成源码、隔离链路及便携包验收。后续顺序为：v1.2.1 增加 Excel 展示防护、轮转诊断日志、时间线补录来源提示及可验证的升级流程；2026-10-16 19:54 已验收并替换日常包。后续优先实际使用休息节奏、长时与规模检查，再考虑打卡正式归档幂等闭环。历史编辑、标签管理与 CLI 按真实需求决定，不扩充常驻后台服务。
