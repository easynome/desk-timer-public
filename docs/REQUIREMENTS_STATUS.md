使用判定：有运行中的工作计时或前台全屏时，优先认定持续使用；其余场景按无输入5分钟推断离席。正在实际休息时仍按休息规则重置。该启发式判据不等于人的实际在场证明，计时事实独立保留。

## 当前到点提醒口径

| 场景 | 实际行为 | 判据 |
|---|---|---|
| 普通桌面、未开勿扰 | 响一次系统音并抬计时面板 | `onTargetReached`、`SELFTEST_DND` |
| 前台全屏 | 不抬窗；响系统音；标记 missed 待确认 | 同上 |
| 应用自身勿扰 | 不抬窗、不响；标记 missed 待确认 | 同上 |
| 普通倒计时到点 | 提醒后继续计时，用户结束时收表 | `ActiveSessions.takeDue` 只触发一次 |
| 番茄工作段/休息到点 | 自动收表；工作段结束后等待用户开始休息 | 番茄自检 |

提示音可选系统 `Notification.IM`、内置 CC0 风铃/滴答、静音。系统事件显式空值时直接静音，调用设置 SND_ALIAS/SND_NODEFAULT 避免隐式默认音。API/设备启动验证与人工听感分开，不据 API 成功断言用户确实听到了声音。

v1.1.0 的性能改动保留了以上到点逻辑，有活动会话时仍按 250ms 检查到点；只在空闲且相关窗口隐藏时停掉 FX Timeline。
